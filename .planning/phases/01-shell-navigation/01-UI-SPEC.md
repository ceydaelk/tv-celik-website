# Phase 1 — UI Design Contract: Shell & Navigation

> Visual and interaction contract for Phase 1 — navbar, footer, WhatsApp FAB, and base styles.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — custom components only |
| Preset | not applicable |
| Component library | none — no radix, no shadcn, no base-ui |
| Icon library | lucide-react (must be added: `npm install lucide-react`) |
| Font | Inter via `next/font/google` — replace Geist Sans in `app/layout.tsx` |

**Rationale (Claude's discretion — CONTEXT.md §Discretion):** Inter is chosen over Geist Sans for this corporate B2B site. Inter has wider language glyph coverage for Turkish characters (ç, ş, ğ, ü, ö, ı), is industry-standard for manufacturing/corporate sites, and has stronger weight differentiation at 700/800 which this site needs for heading impact. Geist Sans reads as developer-tool aesthetic.

---

## Spacing Scale

Tailwind CSS 4 spacing units map directly to px (1 unit = 4px). All tokens below are multiples of 4.

| Token | Value | Tailwind Class | Usage |
|-------|-------|---------------|-------|
| xs | 4px | `p-1` / `gap-1` | Icon gaps, tight inline padding |
| sm | 8px | `p-2` / `gap-2` | Compact badge/tag padding, nav link gaps |
| md | 16px | `p-4` / `gap-4` | Default element padding, card padding |
| lg | 24px | `p-6` / `gap-6` | Navbar horizontal padding, footer cell spacing |
| xl | 32px | `p-8` / `gap-8` | Mega-menu internal padding, mobile menu padding |
| 2xl | 48px | `p-12` / `gap-12` | Footer section vertical padding |
| 3xl | 64px | `p-16` / `gap-16` | Page-level shell padding (reserved for Phase 2+) |

Exceptions:
- Touch targets: WhatsApp FAB minimum 48px × 48px (44px minimum per accessibility, 48px preferred)
- Navbar height: 64px (fixed, not a spacing token — set as `h-16`)
- WhatsApp NAV button horizontal padding: 20px (between sm/md — use `px-5`)

## Typography

Font family: `Inter` — loaded via `next/font/google`, exposed as `--font-inter`, applied to `<html>` via className.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (`text-base`) | 400 (regular) | 1.5 | Paragraph text, footer copy, descriptions |
| Label | 14px (`text-sm`) | 400 (regular) | 1.4 | Nav links, footer links, subcategory items, badges |
| Heading | 20px (`text-xl`) | 700 (bold) | 1.2 | Mega-menu category headers, footer section headers |
| Display | 30px (`text-3xl`) | 700 (bold) | 1.1 | Logo text (if text-based), page H1 (Phase 2+) |

**Weight declaration:** 2 weights — 400 (regular) for body/label, 700 (bold) for headings/display.

Turkish character note: Inter includes full Latin Extended coverage — ç, ş, ğ, ü, ö, ı, İ, Ğ, Ş all render correctly. Specify `subsets: ["latin", "latin-ext"]` in the next/font import.

## Color

All values locked from CONTEXT.md decisions D-08 through D-11.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` | Page background, mega-menu panel background, mobile menu background |
| Secondary (30%) | `#0f172a` | Navbar background, footer background, headings on white sections |
| Surface tint | `#f0f7ff` | Alternating section background (Phase 2+), mega-menu hover row tint |
| Accent (10%) | `#2563eb` | Primary CTA buttons, active nav link underline, mega-menu category header text |
| WhatsApp | `#25D366` | WhatsApp navbar button, WhatsApp FAB — never used for any other element |
| Destructive | `#dc2626` | Not applicable in Phase 1 (no destructive actions in shell) |
| Text on navy | `#ffffff` | All text on `#0f172a` backgrounds (navbar, footer) |
| Text on white | `#0f172a` | All body text on white/tint backgrounds |
| Text muted | `#64748b` | Secondary text — subcategory descriptions, footer legal copy |
| Border | `#e2e8f0` | Mega-menu dividers, footer internal dividers |

Accent (`#2563eb`) reserved for:
- WhatsApp navbar button label/icon (secondary — the button itself is `#25D366`)
- Active/current page nav link indicator (underline or dot)
- Mega-menu category header text color
- Hover state on nav links (text color transition to `#2563eb`)

**Note on navbar WhatsApp button:** Background `#25D366`, text white (`#ffffff`). The green is the element identity — it must not appear on any other element.

## Component Specifications

### 1. Navbar

**File:** `src/components/layout/Navbar.tsx`

**Structure:**
```
<header> (sticky top-0, z-50)
  <nav> (max-w-7xl mx-auto, h-16, flex items-center justify-between, px-6)
    [Logo slot — left]
    [Nav links — center or left-of-right]
    [WhatsApp button — right]
    [Hamburger icon — right, mobile only]
```

**Visual spec:**
- Background: `bg-[#0f172a]` — solid, no blur, no glass effect
- Height: `h-16` (64px) on all screen sizes
- Position: `sticky top-0 z-50`
- Shadow: `shadow-lg` (adds depth against page content)
- Max-width container: `max-w-7xl mx-auto`

**Logo slot:**
- Width reserved: 160px × 40px
- Placeholder: text "TV ÇELİK" in `text-white font-bold text-xl tracking-wide`
- When logo image arrives: `<Image>` component, 160×40, alt="TV Çelik A.Ş."

**Nav links (desktop only, hidden on mobile):**
- Display: `hidden md:flex items-center gap-1`
- Each link: `text-sm font-normal text-white/90 hover:text-white px-3 py-2 rounded-md hover:bg-white/10 transition-colors`
- Active page: `text-white` + `border-b-2 border-[#2563eb]`
- "Hizmetler" link triggers mega-menu on hover — add `group` class on parent wrapper

**WhatsApp navbar button:**
- Display: `hidden md:flex` — visible on desktop, hidden on mobile
- Note (D-03 compliance): CONTEXT.md D-03 says "visible on all screen sizes" — on mobile the WhatsApp FAB (always visible, fixed position) fulfills this requirement. Dual buttons on mobile would create visual clutter; the FAB is the mobile CTA.
- Background: `bg-[#25D366] hover:bg-[#1da851]`
- Text: `text-white text-sm font-bold`
- Padding: `px-5 py-2`
- Border radius: `rounded-full`
- Icon: `lucide-react` `MessageCircle` — 16px, left of text, `gap-2`
- Transition: `transition-colors duration-150`
- href: `https://wa.me/90XXXXXXXXXX` (phone number placeholder — executor fills real number)

**Hamburger button (mobile only):**
- Display: `flex md:hidden`
- Icon: `lucide-react` `Menu` (open) / `X` (close) — 24px
- Color: `text-white`
- Touch target: minimum 48×48px — use `p-3` to pad the icon button

### 2. MegaMenu

**File:** `src/components/layout/MegaMenu.tsx`

**Trigger:** Hover on "Hizmetler" nav link. Implemented via `onMouseEnter` / `onMouseLeave` on a wrapper `<div>` that contains both the trigger link and the panel.

**Panel structure:**
```
<div> (absolute, full-width, top-full, left-0, z-40)
  <div> (bg-white, shadow-xl, border-t border-[#e2e8f0])
    <div> (max-w-7xl mx-auto, px-6, py-8)
      <div> (grid grid-cols-5 gap-8)
        [5 × CategoryColumn]
      </div>
      <div> (border-t border-[#e2e8f0], mt-6, pt-4, text-right)
        "Tüm Hizmetleri Gör →" link
      </div>
```

**CategoryColumn spec:**
- Category header: `text-[#2563eb] text-sm font-bold uppercase tracking-wide mb-3`
- Subcategory list: `space-y-1`
- Each subcategory link: `text-sm text-[#0f172a] hover:text-[#2563eb] hover:translate-x-0.5 transition-all py-0.5`
- No icons in subcategory list (Phase 1)

**Panel visual:**
- Background: `bg-white`
- Top border: `border-t-2 border-[#2563eb]` (accent top stripe — visually anchors to navbar)
- Shadow: `shadow-2xl`
- Animation: none in Phase 1 (deferred to Phase 4 per CONTEXT.md)

**5 Category columns — content:**

| Column | Turkish Header | Subcategories (Turkish) |
|--------|---------------|------------------------|
| 1 | Prefabrik Yapılar | Tek katlı, İki katlı, Villa tipi, Şantiye yapıları, Ofis ve idari, Sosyal tesisler, Eğitim ve sağlık |
| 2 | Hafif Çelik Yapılar | Hafif çelik evler, Villa projeleri, Tiny house, Modüler konut sistemleri, Katlanır / taşınabilir |
| 3 | Konteyner Sistemleri | Yaşam konteyneri, Ofis konteyneri, Şantiye konteyneri, Tiny house konteyner, Katlanır konteyner, Özel tasarım |
| 4 | Endüstriyel Çelik Yapılar | Çelik hangarlar, Fabrika binaları, Depolar, Hayvan barınakları, Tarımsal yapılar |
| 5 | Yapısal Bileşenler | Çelik profiller, Şasi sistemleri, Çatı ve çelik sac, Panel ve kaplama, Özel üretim |

**"Katlanır / taşınabilir" note:** This item is the key differentiator. In Phase 1, render as plain link. Badge/highlight deferred to Phase 3 per CONTEXT.md.

### 3. MobileMenu

**File:** `src/components/layout/MobileMenu.tsx`

**Structure:**
```
<div> (fixed inset-0 z-40, bg-[#0f172a], flex flex-col, md:hidden)
  [Close button — top-right, same position as hamburger]
  <nav> (flex-1, overflow-y-auto, px-6, py-8)
    [Standard links: Ana Sayfa, Kurumsal, Projeler, İletişim]
    [Hizmetler accordion item]
    [WhatsApp button — full width, bottom of nav]
```

**Standard links:**
- `text-white text-lg font-normal py-3 border-b border-white/10 flex items-center justify-between`

**Hizmetler accordion:**
- Trigger row: same style as standard links + `ChevronDown` icon (`lucide-react`, 18px) that rotates 180° when open
- Expanded content: nested category accordion
  - Category trigger: `text-white/70 text-base font-normal py-2 pl-4 border-b border-white/5 flex items-center justify-between`
  - When category expanded: subcategory list at `pl-8` indent
  - Subcategory link: `text-white/60 text-sm py-1.5 hover:text-white transition-colors`

**WhatsApp button (mobile menu bottom):**
- Full width: `w-full`
- Same style as navbar button: `bg-[#25D366] hover:bg-[#1da851] text-white font-bold rounded-full py-3`
- Placed inside nav, after all links, with `mt-6` top margin

**Open/close animation:** none in Phase 1 (deferred). Render with `display: none` / `display: flex` toggle.

**Body scroll lock:** When mobile menu is open, apply `overflow-hidden` to `<body>`. Use `useEffect` in the component.

- Right side: empty in Phase 1 (no social media links yet — Phase 4 scope)

### 5. WhatsAppFAB

**File:** `src/components/common/WhatsAppFAB.tsx`

**Visual spec:**
- Position: `fixed bottom-6 right-6 z-50`
- Shape: circle — `w-14 h-14 rounded-full` (56px diameter)
- Background: `bg-[#25D366] hover:bg-[#1da851]`
- Shadow: `shadow-lg hover:shadow-xl`
- Transition: `transition-all duration-150`
- Icon: `lucide-react` `MessageCircle` — 28px, `text-white`

**Interaction:**
- Entire button is an `<a>` tag linking to WhatsApp deep link
- href: `https://wa.me/90XXXXXXXXXX?text=Merhaba%2C%20bilgi%20almak%20istiyorum.`
- Pre-filled message (URL-encoded): `"Merhaba, bilgi almak istiyorum."`
- `target="_blank" rel="noopener noreferrer"`
- `aria-label="WhatsApp ile İletişime Geçin"`

**Tooltip on hover (desktop only):**
- Text: `"Hemen Yazın"`
- Position: to the left of the FAB — `absolute right-16 whitespace-nowrap`
- Style: `bg-[#0f172a] text-white text-xs px-2 py-1 rounded`
- Show/hide: CSS group hover — `group-hover:opacity-100 opacity-0 transition-opacity`
- Entire FAB wrapped in `<div className="group fixed bottom-6 right-6 z-50">`

**Mobile behavior:** Always visible. No scroll-based show/hide in Phase 1 (deferred to Phase 4).

## Layout Shell Structure

  <body class="min-h-full flex flex-col">

The `<main>` wrapper provides `flex-1` to push the footer to the bottom on short pages.

## Responsive Breakpoints

Using Tailwind defaults (unchanged in Tailwind 4):

| Breakpoint | Width | Navbar behavior |
|------------|-------|-----------------|
| Mobile | < 768px (`md`) | Hamburger menu, no mega-menu, FAB only for WhatsApp |
| Tablet | 768px–1023px | Hamburger or condensed links (treat as mobile for Phase 1) |
| Desktop | 1024px+ (`lg`) | Full nav links + mega-menu + WhatsApp nav button |

Phase 1 uses `md` as the single breakpoint: below `md` = mobile menu, at/above `md` = desktop nav.
