## Spacing Scale

Inherited from Phase 1 UI-SPEC (source: 01-UI-SPEC.md). Tailwind CSS 4 — 1 unit = 4px. All values are multiples of 4.

| Token | Value | Tailwind Class | Usage |
|-------|-------|---------------|-------|
| xs | 4px | `p-1` / `gap-1` | Icon gaps, breadcrumb chevron padding, badge internal gap |
| sm | 8px | `p-2` / `gap-2` | Compact tag padding, stat label/value gap in TrustBar |
| md | 16px | `p-4` / `gap-4` | Card internal padding, feature list item spacing |
| lg | 24px | `p-6` / `gap-6` | Card outer padding on listing page, breadcrumb padding |
| xl | 32px | `p-8` / `gap-8` | Hero content internal padding, callout section padding |
| 2xl | 48px | `py-12` / `gap-12` | Section vertical padding (compact sections: TrustBar) |
| 3xl | 64px | `py-16` / `gap-16` | Section vertical padding (standard sections: ServicesGrid, Detail) |
| 4xl | 96px | `py-24` / `gap-24` | Section vertical padding (hero, callout — generous breathing room) |

Exceptions:
- Hero section height: `min-h-[600px]` — not a spacing token, a layout constraint (CONTEXT.md D-01)
- Hero section maximum: `max-h-[700px]` — capped so content below the fold is visible
- Service card image height: `h-64` (256px) on listing page, `h-80` (320px) on detail page
- Touch targets: all interactive elements minimum 44px tall (inherited from Phase 1)
- TrustSignalsBar: `py-12` (48px) — compact section uses 2xl token rather than full 3xl

## Typography

Inherited from Phase 1 UI-SPEC (source: 01-UI-SPEC.md, app/globals.css).

Font: Inter. Weights locked at 400 and 700 only — no font-medium, no font-semibold (CONTEXT.md §Established Patterns).

| Role | Size | Tailwind | Weight | Line Height | Usage |
|------|------|----------|--------|-------------|-------|
| Body | 16px | `text-base` | 400 (`font-normal`) | 1.5 | Descriptions, feature list items, breadcrumb text, card body copy, hero subheadline |
| Label | 14px | `text-sm` | 400 (`font-normal`) | 1.4 | Trust signal labels, badge text, related service links, category tab labels |
| Heading | 20px | `text-xl` | 700 (`font-bold`) | 1.2 | Section h2 headings on listing page, card titles, callout sub-headline, service detail h1, category page headings |
| Display | 36px | `text-4xl` | 700 (`font-bold`) | 1.1 | Hero h1 headline, FoldableCallout headline, trust stat numbers |

Four sizes, two weights. Hero subheadline uses Body (16px) — the hero h1 at Display (36px) provides sufficient contrast. Service detail h1 uses Heading (20px) — visual differentiation from breadcrumb text comes from weight 700 and copper color, not an extra size step.

## Color

Source of truth: `app/globals.css` `@theme inline {}` block. The Phase 1 UI-SPEC color table is OUTDATED (used navy `#0f172a` / blue `#2563eb`). The actual implemented palette is charcoal/copper.

| Role | Value | Tailwind literal | Usage |
|------|-------|-----------------|-------|
| Dominant (60%) | `#FAFAF9` | `bg-[#FAFAF9]` | Page background for all content sections |
| Shell / secondary (30%) | `#1C1C1C` | `bg-[#1C1C1C]` | Navbar, Footer, Hero overlay, FoldableCallout bg, WhatsAppCTASection bg |
| Surface tint | `#F3F2EF` | `bg-[#F3F2EF]` | TrustSignalsBar bg, alternating section tint, ServiceDetail features block bg |
| Accent (10%) | `#9D7C64` | `text-[#9D7C64]` | See reserved list below |
| Accent hover | `#866A56` | `text-[#866A56]` / `hover:text-[#866A56]` | Hover state on all accent elements |
| Muted | `#8A8680` | `text-[#8A8680]` | Secondary descriptive text, breadcrumb separators, stat labels |
| Border | `#DDDBD6` | `border-[#DDDBD6]` | Card borders, section dividers, feature list item separators |
| WhatsApp | `#25D366` | `bg-[#25D366]` | WhatsApp CTA buttons only — never repurposed |
| WhatsApp hover | `#1da851` | `hover:bg-[#1da851]` | Hover state on WhatsApp buttons only |
| Text on charcoal | `#FFFFFF` | `text-white` | All text on `#1C1C1C` backgrounds |
| Overlay | `rgba(28,28,28,0.65)` | `bg-[#1C1C1C]/65` | Hero image dark overlay; Service card image overlay |

Accent (`#9D7C64`) reserved for:
- Hero section: copper category label strip above h1 (e.g. `"Prefabrik & Çelik Yapı"`)
- ServicesGrid cards: category title text color on card overlay
- ServicesGrid cards: bottom border on hover (`hover:border-b-2 hover:border-[#9D7C64]`)
- ServiceListingPage: `<h2>` category headings
- ServiceDetailPage: `<h1>` service title text
- ServiceDetailPage: feature list checkmark/bullet accent
- FoldableCallout: highlight band or accent stripe (top border or left border of the section)
- BreadcrumbNav: current page (last) segment color
- "Öne Çıkan" differentiator badge background on foldable/portable items
- No use on TrustSignalsBar, no use on body text, no use on WhatsApp elements

### 8. BreadcrumbNav

**File:** `src/components/common/BreadcrumbNav.tsx`
**Used in:** `/hizmetler` page header, `/hizmetler/[kategori]/[hizmet]` page header

**Props:**
```typescript
interface BreadcrumbNavProps {
  items: Array<{ label: string; href?: string }>;
}
// Last item has no href — it is the current page (non-linked)
```

**Structure:**
```
<nav aria-label="Breadcrumb"> (py-4)
  <ol> (flex flex-wrap items-center gap-1 text-sm font-normal text-[#8A8680])
    {items.map((item, i) => (
      <li> (flex items-center gap-1)
        {item.href
          ? <a href={item.href}> (hover:text-[#9D7C64] transition-colors) {item.label}
          : <span> (text-[#9D7C64] font-bold) {item.label}   ← current page in copper
        }
        {i < items.length - 1 && <ChevronRight size={14} className="text-[#DDDBD6]" />}
    ))}
```

**Usage on detail page:**
- `Ana Sayfa` → href `/`
- `Hizmetler` → href `/hizmetler`
- `{Category Name}` → href `/hizmetler#{category-slug}` (anchor to listing page section)
- `{Service Name}` → no href (current page)

## Tailwind CSS 4 Token Notes

Tailwind CSS 4 is configured via `@theme inline {}` in `app/globals.css` — no `tailwind.config.ts` file exists. Custom CSS variables are already declared:

```css
@theme inline {
  --color-charcoal:       #1C1C1C;
  --color-accent:         #9D7C64;
  --color-accent-hover:   #866A56;
  --color-whatsapp:       #25D366;
  --color-whatsapp-hover: #1da851;
  --color-surface-tint:   #F3F2EF;
  --color-muted:          #8A8680;
  --color-border:         #DDDBD6;
  --font-sans:            var(--font-inter);
}
```

In Tailwind CSS 4, these tokens are referenced as `bg-charcoal`, `text-accent`, etc. However, the established pattern in this project uses literal hex values (`bg-[#1C1C1C]`, `text-[#9D7C64]`) based on Phase 1 implementation. **Executors must continue using literal hex Tailwind classes** to match the existing codebase pattern — do not switch to token names mid-project.

Page background is set via `body { background: #FAFAF9; }` in globals.css — pages inherit this automatically.
